# Git-Powered Configuration Management CLI

A Python CLI for managing versioned application configuration files with Git.

## Development setup

Install Poetry, then install the project and its development dependencies:

```powershell
poetry install
```

Run the CLI:

```powershell
poetry run config-cli --help
```

Run the tests:

```powershell
poetry run pytest
```

Configuration and Git workflow commands will be added in the next milestones.
